# Demo video script (~60 s)

Use the fake profile in `docs/demo-profile.json` (popup → Profile tab → ⬆️ Import), never real data. For recording, use a separate Chrome profile with only this extension loaded, so no real data or other extensions show up.

| Time | Screen | Voiceover / caption |
|---|---|---|
| 0:00–0:05 | A long Greenhouse application form, scrolling | "Every job application asks for the same details." |
| 0:05–0:15 | Popup → Profile tab, fields filled, resume uploaded | "Fill your profile once. It stays in your browser." |
| 0:15–0:30 | Open the form → click "Fill standard fields" → fields highlight, report shows what is missing | "One click fills the standard fields. Zero tokens, zero API calls." |
| 0:30–0:40 | Custom question box left empty, report lists it | "Custom questions are left for you, or for your AI." |
| 0:40–0:52 | Claude Code/Desktop: "fill this application" → answers appear in the form | "Optional: your AI answers only those questions, from your resume." |
| 0:52–0:60 | Cursor hovers Submit, user clicks it | "You review and press Submit. The extension never does." |

Recording: macOS `Cmd+Shift+5`, 1280×800 browser window, hide bookmarks and other extensions. Upload to YouTube (unlisted is fine) and paste the link into the Web Store dashboard.
